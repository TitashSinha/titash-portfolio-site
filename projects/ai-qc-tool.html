What it is

A production content quality control system built on the Claude API. It ingests client briefs and reference documents, reviews pre-handoff content against them, and returns structured feedback with inline replacement suggestions — before anything reaches the client.

The problem it solved

At scale, editorial QC becomes the bottleneck. A brief-to-draft cycle with three or four revision rounds does not compound; it just costs time. The tool was built to hold editorial judgment at the QC layer without requiring a senior editor on every review cycle.

How it works

The system accepts a brief, a reference document, and a draft. It runs LLM-based analysis across voice alignment, factual accuracy, brief compliance, and structural coherence. Output is a structured feedback report with flagged passages and suggested rewrites — not a score, but a working editorial document.
